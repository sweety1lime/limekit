В LimeKit появились твики системы: 19 переключателей для Проводника, панели
задач, «Пуска», оформления, советов и рекламы Windows. Любое изменение можно
отменить, и отменяется оно точно.

### Что нового

- **Экран «Твики».** Расширения файлов, скрытые файлы, значки панели задач
  слева, значок поиска вместо поля, тёмная тема, без прозрачности, без
  анимации окон и меню, без советов, рекламы и предложений Microsoft Store,
  без рекламного идентификатора. 16 твиков работают в Windows 10, остальные
  только в Windows 11, и окно так и пишет.
- **Перед изменением видно, что изменится.** Окно показывает каждое значение:
  какое стоит сейчас и каким станет.
- **Выключить значит вернуть как было.** LimeKit записывает значение до того,
  как его тронуть, поэтому выключение возвращает именно твою прежнюю
  настройку, а не «значение по умолчанию». «Вернуть всё» откатывает всё разом,
  «Откат в .reg» сохраняет файл, который вернёт значения и без LimeKit.
- **Чужие изменения не перетираются.** Если после LimeKit значение поменяла
  Windows или ты сам в Параметрах, откат его не тронет и скажет об этом.
- **Честные пометки.** У каждого твика видно, откуда значение (пока у всех
  это то, что пишут сами Параметры Windows), подходит ли он твоей сборке и
  проверял ли его кто-нибудь на ней. Все 16 твиков для Windows 10
  проверены на 22H2 (19045): включены, выключены, результат виден в самой
  Windows, а после отката значения совпадают с прежними байт в байт. Три твика
  только для Windows 11 пока не проверены, и окно так и говорит. Если у тебя
  Windows 11, напиши, сработали ли они.
- **«Перезапустить Проводник».** Часть настроек Проводник читает только при
  запуске. После такого твика на экране появляется кнопка, которая
  перезапускает его так же, как это делают установщики: окна папок открываются
  заново, обои возвращаются сами. Твикам из этого релиза на Windows 10 он не
  нужен, их видно сразу или в новых окнах Проводника.
- «Убрать LimeKit из системы» откатывает и твики.
- Окно больше не вылезает за экран на ноутбуках с 1080p и масштабом 150%.
  Раньше его верх с кнопками мог уйти под панель задач, закреплённую сверху.

Твики работают без прав администратора: меняются только настройки твоей
учётной записи. Поэтому в каталоге нет твиков на групповых политиках, писать в
них может только администратор.

### Исправлено в обоях

- **Веб-обои наконец показывают страницу.** С самой первой версии вместо
  страницы на рабочем столе был пустой тёмный фон: правило, которое не
  выпускает страницу за пределы её папки, по ошибке не пускало и саму страницу.
  Если ты пробовал пример «Аврора» и видел просто темноту, попробуй ещё раз.
- **Видеообои возвращаются после перезапуска Проводника.** Раньше после него
  оставался чёрный экран, пока не перезапустишь LimeKit.
- Фоновый плеер мог упасть, если Проводник перезапускался, пока обои играли.

### Обновление с 0.2.x

Закрой LimeKit через трей («Выход»), распакуй архив поверх старой папки и
запусти `LimeKit.exe`. Библиотека и настройки останутся на месте. Если
распакуешь в другое место, выключи и снова включи автозапуск в настройках,
чтобы он вёл в новую папку.

### Установка

Скачай `LimeKit-0.3.0-win64.zip`, распакуй папку целиком и запусти
`LimeKit.exe`. Нужна Windows 10 или 11, 64 бита.

Сборка не подписана сертификатом, поэтому при первом запуске Windows
предупредит: «Подробнее» → «Выполнить в любом случае». Убедиться, что это
именно моя сборка, можно по SHA-256:

```
<сюда вывод из dist\SHA256SUMS.txt>
```

Если стоит [GitHub CLI](https://cli.github.com/), происхождение архива
проверяется одной командой:

```
gh attestation verify LimeKit-0.3.0-win64.zip -R sweety1lime/limekit
```

Она покажет, каким workflow и из какого коммита собран архив. Список всех
зависимостей лежит рядом с архивом в `LimeKit-0.3.0-sbom.spdx.json`.
