Обои теперь играют и там, где у драйвера видеокарты нет Vulkan, а LimeKit
научился убирать за собой всё, что оставил вне своей папки.

### Что нового

- **Видео и картинки работают без Vulkan-драйвера.** libmpv и ffmpeg внутри
  LimeKit требуют `vulkan-1.dll`, а его ставит драйвер видеокарты. На старых
  встроенных Intel HD, в виртуальных машинах и с «Базовым видеоадаптером
  (Майкрософт)» его нет, и до этой версии обои там просто не запускались. Теперь
  LimeKit везёт загрузчик Vulkan с собой, в папке `vulkan`, и берёт его, только
  если своего в системе нет.
- **Настройки → «Убрать LimeKit из системы».** Останавливает обои, снимает
  автозапуск и ассоциацию файлов `.limekit`, по желанию удаляет библиотеку и
  настройки. После этого папку можно просто удалить. Раньше после удаления
  папки в реестре оставались ассоциация и автозапуск.
- В диагностике появилась строка «Загрузчик Vulkan», а ошибка загрузки libmpv
  теперь объясняет, чего не хватает.

### Обновление с 0.2.0

Закрой LimeKit через трей («Выход»), распакуй архив поверх старой папки и
запусти `LimeKit.exe`. Библиотека и настройки останутся на месте. Если
распакуешь в другое место, выключи и снова включи автозапуск в настройках,
чтобы он вёл в новую папку.

### Установка

Скачай `LimeKit-0.2.1-win64.zip`, распакуй папку целиком и запусти
`LimeKit.exe`. Нужна Windows 10 или 11, 64 бита.

Сборка не подписана сертификатом, поэтому при первом запуске Windows
предупредит: «Подробнее» → «Выполнить в любом случае». Убедиться, что это
именно моя сборка, можно по SHA-256:

```
<сюда вывод из dist\SHA256SUMS.txt>
```

Это первый релиз, который собрал GitHub Actions. Если стоит
[GitHub CLI](https://cli.github.com/), происхождение архива проверяется одной
командой:

```
gh attestation verify LimeKit-0.2.1-win64.zip -R sweety1lime/limekit
```

Она покажет, каким workflow и из какого коммита собран архив. То же работает
для `LimeKit.exe`, `limekit-daemon.exe` и `renderer.exe` из него. Список всех
зависимостей лежит рядом с архивом в `LimeKit-0.2.1-sbom.spdx.json`.
